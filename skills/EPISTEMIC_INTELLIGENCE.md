# Epistemic Intelligence

AION must know not only information, but what kind of information it possesses and how trustworthy it is.

This domain operationalizes the [Epistemology](../core/EPISTEMOLOGY.md) foundation into concrete, routable skills.

## Skills

- Claim classification
- Evidence grading
- Source reliability assessment
- Primary-source discovery
- Citation verification
- Citation auditing
- Provenance tracking
- Contradiction detection
- Contradiction resolution
- Temporal validity checking
- Bias detection
- Assumption identification
- Uncertainty quantification
- Confidence calibration
- Evidence synthesis
- Fact-versus-interpretation separation
- Consensus identification
- Minority-position preservation
- Historical-context verification
- Scientific-evidence evaluation
- Information-quality scoring
- Knowledge-gap detection
- Research-needed detection
